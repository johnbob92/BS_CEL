CELSTARTAB LLC — Offline site (double-click to open)
====================================================

No server needed. Just double-click "index.html" and it opens in your browser,
fully styled, with images, working navigation between pages, and the light/dark
theme toggle.

Start here:
    index.html

Keep this whole folder together — the pages load styles/images/other pages using
paths relative to this folder, so moving individual .html files out on their own
will break them.

Pages:
- index.html ................ Home
- services.html ............. Services (overview)
- services/*.html ........... Cloud Development, Software Engineering,
                              Legacy Modernization, Data & AI, DevOps & SRE
- industries.html ........... Industries
- case-studies.html ......... Case Studies
- company.html .............. Company (overview)
- company/about.html ........ About Us
- company/about/terms-of-service.html
- company/about/privacy-policy.html
- company/how-we-work.html, careers.html, insights.html, events.html
- contact.html .............. Contact (form + Google map)

Tip: the dropdown menus and mobile menu are simplified in this offline copy —
use the links in the footer or the "All Services" / "Company" overview pages to
reach every page. The Google map on the Contact page needs an internet
connection to display.
